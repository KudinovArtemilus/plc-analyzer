# PLC Analyzer

Сбор, запись и анализ данных с контроллеров **Siemens S7** — замена устаревшим
однопользовательским аналайзерам. Написан на **Go**, интерфейс в браузере.

## Возможности

- **Несколько ПЛК одновременно**, каждый со своими сигналами; добавление из интерфейса
- **Опрос S7comm** (S7-300/1200/1500): адреса `DB11.DBW90`, типы BOOL…REAL, масштабирование
- **Частота на каждый сигнал**, автоматическая группировка адресов в блоки, одно соединение на ПЛК
- **Устойчивость к обрыву связи**: переподключение, журнал простоев
- **Live-тренды**: дорожки, синхронный курсор, стоп-кадр, зум, курсоры A/B и Δt
- **Запись по сменам** (А/Б), собственный бинарный формат со сжатием и CRC, хранение N дней
- **История** с прореживанием без потери пиков
- **Выгрузка** участка в PNG (для отчётов) и CSV (под русский Excel)
- **Слепки** — библиотека случаев с категориями
- **Изменение сигналов на лету**, без перезапуска и без обрыва записи
- Оформление по принципам **ISA-101** (High Performance HMI)

## Технологии

Go · SQLite (modernc.org/sqlite, без CGO) · gos7 · HTMX · uPlot · SSE ·
html/template · встраивание статики через `embed` — сборка в один `.exe`.
